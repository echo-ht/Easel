Run a JavaScript program against the current web page to do repetitive multi-step work in one call: read many list items, page through results, fill several fields. Not for a single action: use web_tap/web_type_text for that. code is the body of an async function; return a JSON-serialisable value. The script has no DOM: document, window, location, fetch and every other browser global are undefined; only plain JavaScript (Math, JSON, Array, …) and `easel` are there, and everything easel returns is plain data (always await): easel.snapshot() → {snapshotId, elements:[{ref, role, name, center}]}; easel.read({maxChars, offset}) → page text chunk {text, nextOffset}; easel.queryAll(cssSelector, {fields: ['text','attrs','value','box'], limit, maxChars}) → {items:[{tag, text, attrs, value, box}], total}; easel.query(cssSelector, opts) → first item or null (fields ['count'] → number); easel.text(cssSelector) → visible text (password-like values read as ***); easel.tap(ref); easel.type(ref, text, {enter}); easel.scroll('down'|'up'|'left'|'right', {amount}); easel.navigate(url); easel.wait(ms) or easel.wait({text, timeoutMs}) → true/false; easel.log(...). tap/type use refs from the latest easel.snapshot() in the script. Every action runs through the same execution and recording path as a normal call, including send, post, order, delete and pay. A failed easel call throws an Error whose message starts with the error code. Limits: {{max_actions}} actions, {{max_reads}} reads, {{max_seconds}} s. A navigation that loads a new page ends the script (endedBy=navigation). Returns result (JSON), logs, and actions with each outcome. Call web_observe before acting after it: the page may have changed.
