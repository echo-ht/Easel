## 入口

用户要把视频改成平台要求的比例时用这份技能。先确认原视频尺寸、目标比例、主体位置和是否接受裁切。

## 步骤

1. 用 `ffprobe` 读原视频的宽高、时长、帧率和旋转信息。
2. 主体居中且四周可裁时，用裁切：`ffmpeg -i in.mp4 -vf "crop=ih*9/16:ih,scale=1080:1920" -c:a copy out.mp4`。
3. 不能裁掉信息时，用模糊背景：`ffmpeg -i in.mp4 -filter_complex "[0:v]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=20:20[bg];[0:v]scale=1080:-2[fg];[bg][fg]overlay=(W-w)/2:(H-h)/2" -c:a copy out.mp4`。
4. 先导出 5 秒样片给用户看主体和字幕有没有被裁掉，再处理全片。
5. 处理完用 `ffprobe` 核对输出尺寸、时长和音轨；用 `share_file` 交付。

## 容易出错的地方

- 直接拉伸导致画面变形。
- 裁切把人物头部、字幕或产品切掉。
- 忘记保留音轨。
- 竖屏视频带旋转元数据，重复旋转。

## 怎样算办成(核实证据)

输出视频比例正确、无明显变形、主体完整、音轨保留；样片经用户确认；文件已导出。

## 什么时候停下交给用户

主体位置不明确、需要逐镜头跟踪或原片质量不足以放大时，先说明限制并让用户选择裁切策略。
