## 入口

用户要处理音频或从视频里提取声音时用这份技能。先确认输入文件、目标格式、目标时长和是否需要保留原音质。

## 步骤

1. 用 `ffprobe` 看编码、采样率、声道和时长。
2. 裁剪：`ffmpeg -ss 00:00:10 -to 00:00:35 -i in.wav -c copy out.wav`；重新编码时去掉 `-c copy`。
3. 拼接：先把文件转成相同编码和采样率，再用 concat demuxer。
4. 提取音轨：`ffmpeg -i video.mp4 -vn -c:a copy audio.m4a`；需要通用格式时转 mp3 或 wav。
5. 调音量：`ffmpeg -i in.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 out.wav`。
6. 淡入淡出：`afade=t=in:st=0:d=1`、`afade=t=out:st=...:d=1`。
7. 输出后用 `ffprobe` 核对时长、编码和声道，再用 `share_file` 交付。

## 容易出错的地方

- 不同采样率直接拼接，出现爆音或变速。
- 用 `-c copy` 裁剪到非关键帧，开头有杂音。
- 音量归一化过度，动态全被压平。
- 输出文件覆盖原文件。

## 怎样算办成(核实证据)

输出能播放；时长、格式和声道符合要求；关键片段没有被裁掉；原文件保留；文件已导出。

## 什么时候停下交给用户

需要专业降噪、修音或版权音乐授权时，先说明本机能力和限制，让用户决定。
