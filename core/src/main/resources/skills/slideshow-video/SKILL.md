## 入口

用户有一组图片/卡片，想做成短视频时用。先确认张数、比例、目标时长、平台和是否有配音。

## 步骤

1. 按叙事顺序整理图片，删掉重复和低清图；统一画布比例，例如 9:16。
2. 每张图配一句字幕，控制字数和停留时间；先写脚本再定时长。
3. 用 `run_command` 调 `ffmpeg` 合成：统一尺寸、加淡入淡出或简单转场、按脚本控制每张停留。
4. 有配音时先对齐每段语音，再定图片时长；没有配音时用字幕节奏。
5. 导出后抽查开头 3 秒、转场处和结尾，确认无黑帧、无拉伸、字幕不越界。
6. 用 `share_file` 给用户预览；发布前跑 `content_risk_scan` 检查文案。

## 容易出错的地方

- 图片比例不一，强行拉伸。
- 每张停留时间一样，节奏平淡。
- 字幕太长或超出安全区。
- 转场过多，信息看不清。

## 怎样算办成(核实证据)

视频能播放、比例统一、字幕可读；总时长符合平台；用户确认节奏和内容。

## 什么时候停下交给用户

图片版权或人物肖像不明时停；用户要求使用未授权音乐时先确认授权。
