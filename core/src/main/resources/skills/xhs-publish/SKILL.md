## 入口

用户要把已经定稿的图文或视频发到小红书时用这份技能。先确认：账号、标题、正文、话题、图片或视频（二选一）、是否立即发布。

## 步骤

1. 发布前检查：标题不超过 20 个全角字；正文完整；图片数量和张数符合小红书要求，或视频能正常播放；没有敏感信息、内部路径、Key 和工具痕迹；话题与内容相关。
2. 把最终标题、正文、话题和素材给用户确认。用户已经明确说「直接发」时可以不重复确认，但仍要检查。
3. 用 `phone_launch_app` 打开小红书，进入「我 → 创作中心 → 发布笔记」（或当前版本对应的发布入口）。
4. 选择「图文」或「视频」，上传素材。等上传和预览完成，不要在上传没结束时填正文。
5. 填标题、正文和话题。话题用输入 `#` 后从联想里选择真正的话题，不要只留一个井号文本。
6. 检查封面、标题、正文、话题、可见范围和账号，确认无误后点发布。
7. 发布后核实：页面离开编辑页，或者在「我 → 笔记」里看到这条新笔记。只看到按钮被点过不算成功。

## 容易出错的地方

- 小红书对自动化操作有风控，可能要求验证、限流或退出登录；优先用测试号、小流量，重要内容人工复核。
- 上传图片/视频需要时间，预览没出现就点发布容易发出空笔记。
- 标题按全角字计算，超限会被截断或拒绝。
- 话题必须从联想里选中，纯文本的 `#` 不算绑定话题。
- 不要重复点发布；网络慢时先看笔记列表里有没有已经发出去。

## 怎样算办成(核实证据)

在「我 → 笔记」或发布成功页看到这条内容，标题和封面正确；能看到笔记链接或笔记 ID 时记下来。

## 什么时候停下交给用户

出现登录、验证码、滑块、实名、风险提示，或平台要求人工确认时，停下来把手机交给用户处理；用户处理完再从当前页面继续核实，不要从头重发。
