## 入口

用户问「账号为什么没起色」「帮我看看主页」时用。先确认平台、账号和观察窗口，再读账号画像。

## 步骤

1. 读「内容工作台」里的账号画像；没有画像时先用 `profile-builder` 建一份最小画像。
2. 用 `phone_launch_app` 打开平台，`phone_observe` / `phone_query` 读取公开主页：简介、置顶、最近 10–20 条、更新频率、置顶数据。
3. 把内容按题材和形式分组，找重复出现的选题、开头和封面套路；只记录看得见的，不猜后台数据。
4. 用 `content_metrics_list` 和 `content_attribution_summary` 看本机已有指标，和主页公开互动对照；口径不同就分开说。
5. 诊断分四块：定位是否清楚、内容是否有稳定栏目、开头和封面是否可识别、发布节奏是否可持续。
6. 输出 3–5 条动作，每条写清改什么、为什么、下一篇怎么验证。

## 容易出错的地方

- 用单条爆款概括整个账号。
- 把粉丝数当唯一目标，忽略收藏、评论和关注转化。
- 没看到后台数据却编造完播率、涨粉来源。
- 建议太泛，例如「多互动」「提高质量」。

## 怎样算办成(核实证据)

诊断里每个判断都有主页样本或本机指标；区分事实与推断；至少给出 3 条下一篇能执行的动作。

## 什么时候停下交给用户

需要登录私密后台、验证码或付费数据时请用户接管；账号不是用户本人时不要继续抓取。
