## 入口

用户要把回答或文章发到知乎时用这份技能。先确认是回答哪个问题、文章主题、目标读者、是否有真实经历或资料。

## 步骤

1. 读原问题，确认回答真的在回答它，不是借题发挥。
2. 结构用“结论先行 → 理由或经历 → 证据 → 适用边界”。长回答每 300-500 字加一个小标题。
3. 引用数据、研究和他人观点时写出处；没有来源就删掉或改成个人判断。
4. 用 `phone_launch_app` 打开知乎，找到问题或创作入口，粘贴定稿。
5. 检查标题、正文、图片、引用和可见范围；需要声明利益相关时写清楚。
6. 发布后在个人主页或问题下核实；用 `content_publish_log_add` 记录结果。

## 容易出错的地方

- 回答偏离原问题，读者不知道在说什么。
- 把推测写成事实，或引用二手转述。
- 通篇情绪输出，没有可验证的信息。
- 商业内容不声明利益相关。

## 怎样算办成(核实证据)

回答直接回应问题；关键结论有依据；页面能看到已发布内容；发布记录已写入。

## 什么时候停下交给用户

涉及专业医疗、法律、金融建议，或需要实名和资质认证时，让用户确认或亲自发布。
