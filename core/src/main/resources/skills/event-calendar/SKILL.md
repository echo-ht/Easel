## 入口

用户要做月度/季度内容排期，或问「最近有什么节点能用」时用。先确认年份、地区、行业和平台。

## 步骤

1. 列固定节点：公历节日、传统节日、行业纪念日、平台年度活动；日期不确定的标「待核实」。
2. 每个节点写：和账号定位的关系、目标读者、可做的 1–3 个选题、需要提前几天准备。
3. 区分「借势」和「硬蹭」：没有真实连接点的节点直接删。
4. 按制作成本排优先级：低成本清单/卡片优先，高成本视频只留一个重点节点。
5. 用 `content_plan_add` 写入日历，排期至少提前 3–7 天；需要素材的先建制作计划。
6. 输出时标明哪些日期来自公开日历、哪些需要用户确认。

## 容易出错的地方

- 农历日期和调休安排没核实。
- 所有节点都做，产能崩掉。
- 敏感纪念日拿来做促销。
- 节点当天才开始做。

## 怎样算办成(核实证据)

每个节点有来源或待核实标记；选题和账号定位有连接；日历里有真实排期和提前量。

## 什么时候停下交给用户

涉及宗教、政治、灾难或敏感纪念日时先让用户判断；日期无法确认时不要写死。
