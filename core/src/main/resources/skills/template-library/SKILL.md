## 入口

用户说「以后都按这个来」「帮我沉淀模板」时用。先确认模板类型、适用平台和不适用场景。

## 步骤

1. 从已发布内容里找重复结构，不要凭空发明模板。
2. 每个模板写：名称、适用平台/题材、结构槽位、示例、禁用条件、版本日期。
3. 槽位用可替换标记，例如 `{读者痛点}`、`{证据}`、`{行动}`；不要留无法填写的空。
4. 图文模板和视频模板分开；封面模板标注尺寸、字数上限和安全区。
5. 把模板文件放到本机目录，用清晰文件名保存；需要给用户时 `share_file`。
6. 每次使用后记录一次「有效/需调整」，模板升级时保留旧版本，不静默覆盖。

## 容易出错的地方

- 模板变成套话生成器。
- 一个模板硬套所有平台。
- 没有禁用条件，导致事实被模板带偏。
- 覆盖旧版本后无法回溯。

## 怎样算办成(核实证据)

模板有示例和边界；用户能直接填空使用；版本可追溯；至少一条真实内容验证过。

## 什么时候停下交给用户

模板涉及品牌口吻、法律声明或医疗金融表述时先让用户确认；没有真实样本时只建草稿，不宣称有效。
