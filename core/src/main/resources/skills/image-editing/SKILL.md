## 入口

用户要处理图片但不需要 AI 生图时用这份技能。先确认输入文件、目标尺寸、格式、体积上限和是否保留原图。

## 步骤

1. 用 `run_command` 读图片尺寸、格式和文件大小。
2. 裁剪和缩放优先用 Pillow；需要批量处理时写一个小 Python 脚本，输出到新目录。
3. 压缩 JPEG 时逐步降低质量，直到体积符合平台限制，同时检查画质。
4. 加水印时用用户提供的 logo 或文字，位置避开平台 UI 和主体。
5. 转格式时注意透明通道：PNG 转 JPEG 要铺白底。
6. 输出后重新读尺寸和大小，用 `share_file` 交付；保留原图。

## 容易出错的地方

- 反复压缩导致画质明显下降。
- 改尺寸时没有保持比例，画面变形。
- 透明背景转 JPEG 后变黑。
- 覆盖原图或把水印盖在主体上。

## 怎样算办成(核实证据)

输出尺寸、格式和体积符合要求；画面无明显变形；原图保留；文件能打开并已导出。

## 什么时候停下交给用户

需要抠图、修脸、去物体或 AI 生图时，说明本技能不做这些，转对应能力并先确认费用。
