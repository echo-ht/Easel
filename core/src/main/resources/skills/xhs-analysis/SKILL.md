## 入口

用户要看账号表现、笔记数据、爆款规律或评论区时用这份技能。先确认分析对象：账号、单篇笔记、关键词搜索还是一组竞品。

## 步骤

1. 优先用手机上的小红书 App 或网页读取真实页面。用 `phone_launch_app` 打开 App，用 `phone_query` 看当前屏，用 `phone_collect` 收集列表；网页用 `web_navigate` 和 `web_read_page`。
2. 每条数据记下来源：账号名、笔记标题、页面上的点赞/收藏/评论数、读取时间。读不到就写读不到。
3. 单篇分析看：标题钩子、封面信息、开头三行、正文结构、话题、发布时间、评论区高频问题。
4. 账号分析看：近 10-20 篇的选题分布、互动中位数、明显高于中位数的 3 篇、更新频率和内容形式。
5. 竞品分析至少看 2 个账号，找共同点和差异点，不把单个爆款当规律。
6. 结论写成“观察 → 证据 → 可执行动作”，每条结论都指向具体笔记或评论。

## 容易出错的地方

- 把点赞数当播放量，或把单篇爆款当稳定规律。
- 页面显示的是缩写或区间，不能写成精确数字。
- 只看看得顺眼的样本，忽略低表现内容。
- 评论区截图里的用户信息不要原样公开。

## 怎样算办成(核实证据)

交付里每个数字都有读取时间和来源；结论能对应到具体笔记或评论；区分了页面事实和推断；样本范围写清楚。

## 什么时候停下交给用户

页面要求登录、验证码或付费数据时，请用户接管；涉及他人隐私或未公开数据时，不继续收集。
