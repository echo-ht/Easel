# 字体层级与中文排版

## 铁律：字越大越细

字号越大，字重越轻；只有小字才用重字重。大标题用 700-900 粗黑体会立刻像廉价信息图 banner。高级排版的大标题通常是 200-500。

## 字体族

Android 上只用系统族，避免网络字体和缺失字体：

- 杂志系：标题和正文用 `serif`。
- 瑞士系：标题和正文用 `sans-serif`。
- kicker、meta、label、序号：用 `monospace`，大写并加 `0.18-0.22em` 字距。
- 中英混排可在同一 `font-family` 里加 `sans-serif` 或 `serif` 兜底，不引用具体字体文件。

## 字号层级（1080x1440 竖版）

杂志系：

- Display 大标题 110-124px，字重 500，字距 +0.02em
- 章标题 80-88px，字重 500；中标题 52-56px
- 金句 60-64px，字重 500
- 导语 28px；正文 24-26px
- kicker、meta、label 20px，`monospace` 大写

瑞士系：

- Hero 巨标题 180-240px，字重 200
- 章标题 100-120px，字重 300；巨型数字 180-200px，字重 200
- 导语 30px；正文 26px，字重 400
- 分类标签 22px，字重 600；meta 20px，`monospace`

## 最小字号死线

- 正文至少 28px，导语至少 30px，caption、label、水印至少 20px，绝对死线 18px。
- 放不下就删字，不缩字号。手机上小于 18px 的小字白做。

## 中文标题分档

| 标题字数 | 字号 |
|---|---|
| 不超过 6 字 | 120-132px |
| 7-10 字 | 96-108px |
| 两行各不超过 8 字 | 88-96px |
| 有行 9-12 字 | 80-84px |

- 3:4 画幅最多 2 行，每行不超过 8 字。要 3 行就换封面型骨架，别把标题缩到 80px 以下。
- 中英混排时在语义处手动 `<br>` 断行，避免 CJK 自动断出孤字行。
- 行距：标题 1.15-1.25，中文正文 1.6-1.75。中文标题可加 +0.02em 字距，正文不加。

## 层级对比

高级感来自强层级：Display 与正文字号比至少 4:1。用字号、字重和颜色（ink 对 muted）三者拉开层级，而不是把所有字都加粗。
