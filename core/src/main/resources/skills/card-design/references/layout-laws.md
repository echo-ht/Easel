# 布局法则：填满画幅（治死空白）

> 社媒卡是单独滑看的，不像杂志靠对开页吸收留白。欠填的卡会被读成“PPT 缺了一个元素”。这是硬门禁。

## 硬规则

- 内容纵向跨度至少 80%（1440px 画幅至少 1152px）。
- 任何无理由的纯空白带超过 15% 画高（1440px 画幅超过 216px）即失败。
- 渲染后看 `render_card` 返回的 `audit`，全部通过才交付。

## 四带密度自检

把成图纵切四条各 25%，逐带看有没有内容：

- 通过：底部带有实质内容；相邻两带不同时为空；整体填充至少 75%。
- 典型失败：内容堆在上两带，第三、四带近空，形成头重脚轻和底部死空白。

## 内容少时怎么办

绝不做：

- 用 `flex:1` 把内容顶到垂直居中，下面留死空白。
- 加装饰 blob、圆圈、水滴、贴纸或无关插画填空。
- 无脑放大标题到占满，标题该多大有 typography 规则。

要做（从上到下依次尝试）：

1. 扩内容：补一行“为什么”、例子、类比、数据、边栏注解，把 3 条要点补到 4-5 条。
2. 加结构化承载：账本行、时间线、管线步骤、对比表、矩阵格，这些天然吃高度且有信息量。
3. 换更省高度或更高容量的骨架。
4. 真内容就是少，换 1:1 画幅 1080x1080，别硬撑 3:4。
5. 呼吸型骨架（金句、单句陈述）必须补三个锚点：顶部 kicker 或日期、底部来源或出处行、其上方一条发丝线。

## 垂直节奏

- 首尾各留约 8% 边距（80-110px），作为有意的呼吸，不算死空白。
- 主标题下留至少 28px，小标题下至少 16px。
- 多个内容块用相等间距，间距 token 只用 8、12、16、24、32、40、48、64、80、96px。
- 用 `justify-content: space-between` 或均等 gap 从上铺到下，不要让内容挤在顶部。
- 高度预算参考：账本每行 100-140px；管线每步约 96px，5 步约 480px；矩阵 3x2 每格约 380px。

## 溢出修正

- 超出 1-40px：上移或收一处间距。
- 超出 40-90px：压局部间距并缩一块。
- 超出 90-160px：略缩标题或压一段。
- 超出 160px：换高容量骨架或有意删内容。
- 改完再查底部空白，别为了不溢出又把内容顶上去。

## 网格

- 瑞士系：严格 12 栏、左对齐、非对称留白，标题坐左上，不居中。
- 杂志系：单栏或双栏，衬线正文，用 1-2px 细线和账本行分隔，不靠浮起卡片。
- 间距只用上面的 token，不随手写 px。
