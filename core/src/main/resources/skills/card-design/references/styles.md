# 风格库（选一个，整套照做）

> 卡片没有唯一正确的美。先让用户挑风格；没挑就按内容、平台和账号画像推荐 2-3 个。
> 选定后整套卡片只用这一套字体、配色和装饰。字体只用 Android 系统族：`sans-serif`、`serif`、`monospace`。

## 怎么给用户选

给用户看“风格名 + 一句话 + 适用”，让 ta 选一个。没主意时按品类推荐：科技/产品→瑞士极简或极客终端；知识/深度→杂志编辑；国风/文化→新中式墨韵；生活/情感→奶油温柔或植物清新；年轻/潮流→多巴胺 Y2K；高端/影视→高奢黑金；学习/清单→手账贴纸。

## 1. 瑞士极简 Swiss Minimal

- 一句话：白底黑字、克制点缀、网格留白，冷静专业。适用科技、AI、产品、干货、数据。
- 字体：`sans-serif`；大标题字重 200-300，正文 400，标签用 `monospace` 大写加字距。
- 配色：底 `#fafaf8`、字 `#0a0a0a`、次要 `#737373`、发丝线 `#d8d8d4`、点缀只一个（克莱因蓝 `#002FA7`、柠檬黄 `#FFD500` 或安全橙 `#FF6B35`）。
- 版式：左对齐、强网格、非对称留白。零圆角、零阴影、禁渐变；靠色块、发丝线和序号分层。
- 装饰：一个小实心方块做 kicker 前缀，或一个巨大细体序号。

## 2. 杂志编辑 Editorial Magazine

- 一句话：暖纸、衬线、电子墨水质感。适用知识、深度、书评、生活方式、观点。
- 字体：`serif`；大标题字重 300-500，正文 400，kicker 用 `monospace`。
- 配色：暖纸 `#f3f0e8` 或 `#f5f1e8`、深墨 `#0a0a0b` 或 `#16251b`、次要 `#68625a`、点缀稀用 `#315d93` 或 `#9b5a2e`。
- 版式：单栏或双栏，账本行加细线分隔，不靠浮起卡片。小圆角 4px。
- 装饰：极淡纸纹或径向墨晕，截图只给极柔阴影。

## 3. 新中式墨韵 Chinese Ink

- 一句话：宣纸墨色、朱砂印章、竖排点睛。适用国风、文化、茶、诗词、节气、非遗。
- 字体：`serif`；标题字重 500-700，可用 `writing-mode:vertical-rl` 做点睛标题。
- 配色：宣纸 `#f3efe4` 或 `#efe9dd`、墨 `#1a1a1a`、次要 `#6b6357`、朱砂 `#a8322d`、可加淡金 `#b08d57`。
- 版式：大留白但内容仍要铺满，用竖排标题、长段和印章块占位，细墨线分隔。
- 装饰：朱砂方印，水墨晕染角，竖排小标题。

## 4. 奶油温柔 Cream Soft

- 一句话：奶油底、莫兰迪柔色、圆润温暖。适用生活、情感、护肤、美食、家居、治愈。
- 字体：`sans-serif`；标题 500-700，正文 400，字色用深棕 `#7A6A5C`。
- 配色：奶油 `#FAF6EF` 或 `#F5F0E8`、燕麦 `#EDE4D3`、莫兰迪点缀绿 `#A3B0A0`、蓝 `#8CA3AD`、粉 `#C9A9A6`、紫 `#9B8AA0`，选一个。
- 版式：允许 20-28px 圆角，块间大间距，可居中。
- 装饰：柔和圆角色块、极淡投影、小圆点或短波浪线。

## 5. 多巴胺 Y2K Dopamine

- 一句话：高饱和撞色、粗黑字、大色块。适用潮流、穿搭、消费、娱乐、校园。
- 字体：`sans-serif`；标题 900，正文 500。
- 配色：大色块底，柠檬黄 `#FFD500`、荧光绿 `#C5E803`、亮粉 `#FF5CA8` 或克莱因蓝 `#002FA7`；黑字或白字，撞色不超过三种。
- 版式：大色块分区、贴纸标签、3-4px 粗描边，可轻微倾斜。
- 装饰：粗黑框、星形或圆形贴纸、大号数字、马克笔高亮块。

## 6. 高奢黑金 Luxe Noir

- 一句话：近黑底、暖白、细金线，克制神秘。适用高端、影视、游戏、品牌发布。
- 字体：`serif` 做大标题，`sans-serif` 做正文，`monospace` 做标签。
- 配色：底 `#0e0d0c` 或 `#12100d`、字 `#ece2cf`、次要 `#9a8c75`、金 `#d4a04a`。
- 版式：大留白、细金线、居中或左对齐都行，但层级必须清楚。
- 装饰：细金线框、低透明度纹理、少量金色小标签。

## 7. 手账贴纸 Journal Sticker

- 一句话：奶白纸、胶带色块、手写便签。适用学习、清单、日常、复盘、干货整理。
- 字体：`sans-serif` 400-500；关键句可加手写感下划线。
- 配色：奶白 `#FBF7F0`、胶带色鹅黄 `#F3D9A4`、薄荷 `#B8D8C8`、藕粉 `#E8C4C4`、天蓝 `#BCD3E8`，低饱和多色。
- 版式：便签块轻微旋转 ±2°，胶带条、虚线、勾选框，但整体对齐网格。
- 装饰：胶带条、便利贴、手写圈注、方框勾选。

## 8. 极客终端 Terminal

- 一句话：深色终端、等宽绿字、代码感。适用编程、技术、命令行、AI 工程、教程。
- 字体：`monospace`；标题也用等宽，靠字号分级。
- 配色：底 `#0d1117` 或 `#0a0e14`、主字 `#c9d1d9`、强调终端绿 `#3fb950` 或琥珀 `#e3b341`、注释灰 `#6e7681`。
- 版式：像终端窗口，顶部路径行、`$` 提示符、代码块 `#161b22`、行号，左对齐。
- 装饰：`>` 提示符、代码块、光标方块、`[TAG]` 标签。

## 9. 植物清新 Botanical Fresh

- 一句话：米白、鼠尾草绿、陶土，自然清爽。适用健康、园艺、户外、轻食、瑜伽、可持续。
- 字体：`sans-serif` 300-500，或 `serif` 做标题。
- 配色：米白 `#f6f4ee`、鼠尾草绿 `#7d9b76` 或 `#a7bda0`、陶土 `#c08457`、墨绿字 `#2f3b2c`。
- 版式：大呼吸留白、细线、植物线描点缀，左对齐。
- 装饰：单线叶片或枝条 SVG、细圆点、自然色标签。

## 通用铁律

- 内容纵向跨度至少 80%，无理由空白不超过 15%，以 `render_card` 返回的审计为准。
- 一套卡片一个风格、一套颜色，全程不换。
- 点缀克制；除多巴胺外，高饱和色面积要小。
- 默认禁渐变文字、emoji 图标、玻璃拟态；正文不小于 28px。
