## 入口

用户要给视频加外文字幕或双语字幕时用。先确认源语言、目标语言、是否保留双语和术语表。

## 步骤

1. 读取 SRT/VTT 原文，先统计条数、时间码和说话人；格式不合法先修。
2. 建立术语表：人名、品牌、产品、专业词；全片统一译法。
3. 逐条翻译，保留原时间码和序号；每条控制在目标语言可读长度，通常不超过两行。
4. 双语模式先放原文再放译文，或按用户指定顺序；不要破坏时间轴。
5. 翻译后检查：漏条、时间码错位、标点、数字、否定和限定条件。
6. 导出新字幕文件，用 `ffmpeg` 做一次挂载预览；用 `share_file` 给用户。

## 容易出错的地方

- 时间码被翻译工具打乱。
- 术语前后不一致。
- 为了短而删掉否定或条件。
- 双语字幕超出画面安全区。

## 怎样算办成(核实证据)

条数和时间码与原文一致；术语统一；关键否定和数字准确；预览能正常显示。

## 什么时候停下交给用户

涉及法律、医疗或金融专业内容时建议专业审校；源字幕缺失严重时先补源。
