## 入口

用户要整理、查找或统计内容素材时用这份技能。先确认范围：当前对话的 `/workspace`、手机「下载/Easel」内容库，还是两者一起。

## 步骤

1. 用 `search_files` 列出 `/workspace` 里的文件，按类型和主题分组；内容库由用户在「内容工作台 → 素材库」查看。
2. 文件命名统一为 `主题-类型-序号.扩展名`，例如 `秋季穿搭-cover-01.png`。
3. 建目录：`/workspace/assets/<主题>/images`、`videos`、`audio`、`copy`，中间稿和成品分开。
4. 删除前先确认是临时文件；原始素材和成品不删。
5. 生成的成品用 `share_file` 导出到手机内容库，方便下次直接取用。
6. 给用户一份清单：文件名、类型、大小、来源、用途和缺失项。

## 容易出错的地方

- 把原始素材和生成图混在一起，找不到源文件。
- 覆盖同名文件。
- 删除用户唯一的一份素材。
- 只看扩展名，不检查文件是否能打开。

## 怎样算办成(核实证据)

目录结构清楚；文件能打开；成品已导出；清单与实际文件一致；没有误删原始素材。

## 什么时候停下交给用户

需要删除、移动大量文件或清理内容库时，先给计划让用户确认。
