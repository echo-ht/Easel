## 入口

用户第一次使用内容工作台，或账号还没有画像时用。不要一次抛出长问卷。

## 步骤

1. 先问三个最小问题：账号是谁、提供什么价值、主要发在哪个平台。
2. 继续按顺序收集：主要题材/栏目、目标受众和痛点、语气和视觉风格、更新节奏、想做什么/不做什么/红线。
3. 每问一个问题就复述确认，信息不足写 `[待补充]`，不替用户编。
4. 用户给公开主页时，可以打开看近期内容，提炼题材和风格；抓不到就说明。
5. 整理成六部分：定位、内容方向、风格、受众、平台、偏好与红线、长期记忆。
6. 请用户到「内容工作台 → 账号画像」保存；保存后逐项核对文本一致。

## 容易出错的地方

- 用「热爱生活、分享美好」这类空话填满。
- 把用户没说过的人设写进去。
- 一次问十几个问题。
- 把平台算法猜测当账号定位。

## 怎样算办成(核实证据)

六部分都有内容或明确待补充；每条关键定位来自用户自述或公开内容；用户确认保存。

## 什么时候停下交给用户

用户还没决定定位或红线时停；需要登录私密后台时请用户接管。
