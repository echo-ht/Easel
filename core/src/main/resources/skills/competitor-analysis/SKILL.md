## 入口

用户要研究同赛道账号时用这份技能。先确认分析目的：找选题、学结构、看变现，还是判断竞争强度。

## 步骤

1. 选 2-5 个真正可比的账号：同一人群、同一平台、相近阶段。不要拿头部账号直接压自己。
2. 每个账号记录：定位、内容形式、更新频率、近 20 篇选题、互动中位数、置顶和合集、主页引导。
3. 拆 3 篇高表现内容：标题、封面、开头、结构、证据、CTA、评论区反馈。
4. 找可迁移的做法和不可迁移的条件（团队、资源、出镜人、供应链）。
5. 输出对比表，最后给 3 条能立刻执行的动作和 3 条不要照搬的地方。

## 容易出错的地方

- 只抄标题和形式，没看到背后的资源和受众差异。
- 把粉丝量当唯一指标，忽略互动质量和内容成本。
- 只分析爆款，不看稳定输出的内容。
- 把推测写成事实，例如猜测对方投流或收入。

## 怎样算办成(核实证据)

每个结论都有具体账号和内容样本；区分了页面事实与推断；动作建议符合用户当前产能；没有公开他人隐私。

## 什么时候停下交给用户

需要登录、付费或后台数据时请用户接管；涉及商业机密和未公开合作时停止收集。
