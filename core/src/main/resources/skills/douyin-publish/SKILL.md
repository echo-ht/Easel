## 入口

用户要把已经定稿的视频或图文发到抖音时用这份技能。先确认账号、标题、简介、话题、封面、素材和发布时间。

## 步骤

1. 检查视频能播放、画幅和时长符合要求；图文至少 2 张，顺序正确，没有敏感信息、内部路径和工具痕迹。
2. 把最终标题、简介、话题和封面给用户确认。用户明确说“直接发”时可以不重复确认，但仍要检查。
3. 用 `phone_launch_app` 打开抖音，进入「我 → 创作者中心 → 发布作品」或当前版本的发布入口。
4. 选择视频或图文，上传素材，等转码和预览完成再填文字。
5. 填标题和简介；话题从联想里选择，不要只留 `#` 文本；检查封面和可见范围。
6. 点发布后核实：离开编辑页，或在作品列表看到新作品。只看到按钮被点过不算成功。
7. 发布成功后用 `content_publish_log_add` 记录平台、标题和链接；失败也记录真实原因。

## 容易出错的地方

- 上传未完成就点发布，容易发出空作品。
- 视频比例、时长或文件大小不符合平台要求。
- 抖音可能要求短信、滑块或实名验证；不要绕过。
- 网络慢时重复点发布，可能发出多条。

## 怎样算办成(核实证据)

在作品列表或发布成功页看到这条内容，标题、封面和可见范围正确；能拿到链接或作品 ID 时记下来。

## 什么时候停下交给用户

出现登录、验证码、短信验证、实名、风险提示或人工审核时，把手机交给用户；处理完从当前页面继续核实。
