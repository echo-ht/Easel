## 入口

用户要建画像、改定位、分析账号、补充风格或红线时用这份技能。画像文件在「内容工作台」的「账号画像」里，是一个 markdown 文件。

## 步骤

1. 先读当前画像。已经有的内容不要重复问；只补缺口。
2. 一次问一个问题，按这个顺序收集：画像名/账号是谁 → 提供什么价值 → 主要题材和栏目 → 语气和视觉风格 → 核心受众和痛点 → 主要平台和更新节奏 → 想做什么/不做什么/红线。
3. 用户给了社媒主页链接时，可以打开 App 或网页看近期公开内容，提炼题材、风格和高互动特征；抓不到就说明抓不到，改由用户口述，不要编造数据。
4. 把结果整理成画像的六个部分：定位、内容方向、风格、受众、平台、偏好与红线、长期记忆。每个字段信息不足就写 `[待补充]`，并列出还需要用户回答的具体问题。
5. 产出完整的画像草稿后，请用户到「内容工作台 → 账号画像」粘贴保存；用户同意时也可以把其中适合短句记忆的偏好用 `profile_edit` 记下。
6. 保存后回执：哪些来自用户自述、哪些来自链接分析、哪些仍待补充。

## 容易出错的地方

- 不要用通用套话把画像填满；不确定就标 `[待补充]`。
- 不要把别的账号的数据当成这个账号的。
- 画像不是一次性文件；发布复盘后要把验证有效的经验补进「长期记忆」。

## 怎样算办成(核实证据)

画像六个部分都有内容或明确的 `[待补充]`；用户确认保存后，能在「内容工作台」里看到同样的文本。

## 什么时候停下交给用户

需要登录平台看私密数据、或用户还没决定定位/红线时，停下来问清楚，不要替用户拍板。
