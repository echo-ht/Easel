## 入口

任何内容在点发布之前都可以用这份技能。先确认平台、账号、内容形式和最终素材。

## 步骤

1. **内容**：标题与正文一致；没有错别字；事实、数字、引用有来源；没有绝对化和未经证实的承诺。
2. **素材**：图片/视频能打开；顺序、画幅、时长和大小符合平台；封面文字不压边；没有水印和版权问题。
3. **账号**：当前登录的是正确账号；可见范围、评论和转发设置符合预期。
4. **隐私**：没有 API Key、内部地址、代理、私有路径、订单号、手机号和他人隐私。
5. **平台**：标题、正文、话题、标签和发布时间符合限制；需要声明广告或转载时已声明。
6. **风控**：是否需要验证码、实名或人工审核；重要内容是否已让用户最后确认。
7. 输出“通过 / 需修改 / 必须停下”三项结论，列出具体问题和修改建议。

## 容易出错的地方

- 只检查文字，不检查素材和账号。
- 把平台预览当成最终发布效果。
- 忽略图片里的隐私信息和屏幕截图。
- 用户说“直接发”就跳过风险检查。

## 怎样算办成(核实证据)

清单逐项有结论；需要修改的地方已改；用户确认过最终标题、正文、素材和账号；没有未解决的高风险项。

## 什么时候停下交给用户

出现平台风控、版权争议、医疗金融承诺、他人隐私或用户未确认的付费动作时，停止发布。
