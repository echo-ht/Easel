## 入口

用户要看已发布内容表现，或要把数据记下来复盘时用。先确认平台、内容范围和时间窗口。

## 步骤

1. 用 `phone_launch_app` 打开平台创作者后台，`phone_observe` / `phone_query` 读取真实数字。
2. 找到 `content_publish_log_list` 里的发布记录；能对应上的记下 publishId。
3. 用 `content_metrics_add` 逐条记录：触达、点赞、收藏、评论、分享、涨粉。区间值或缩写原样写进 note。
4. 同一内容隔一段时间再记一次快照；不要覆盖旧快照。
5. 用 `content_attribution_summary` 汇总平台表现和 Top 内容；需要明细时用 `content_metrics_list`。
6. 结论分两层：事实（数字、变化、样本量）和解释（可能原因、下一步验证）。没有数据支持的原因不写成结论。

## 容易出错的地方

- 把点赞当播放，或把区间值写成精确值。
- 不同平台口径混在一起比较。
- 只记爆款，不记账号基线。
- 把相关当因果，例如「换封面导致爆了」。

## 怎样算办成(核实证据)

每个数字有平台、内容和读取时间；快照可回读；汇总口径一致；解释部分明确标注为推断。

## 什么时候停下交给用户

需要登录、验证码、付费数据工具时请用户接管；涉及他人隐私或后台敏感信息时不继续收集。
